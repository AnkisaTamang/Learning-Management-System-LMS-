# Complete LMS (Learning Management System)

A full-stack Learning Management System with separate panels for Admin, Educator, and Student roles. Built with React frontend and PHP backend with MySQL database.

## 🚀 Features
- Admin Panel
- Educator Panel
- Student Panel
- Course Management
- Payment System
- Progress Tracking

## 🛠️ Tech Stack
- React
- PHP
- MySQL
- Tailwind CSS

## 🎯 Project Description
This LMS allows users to learn, teach, and manage courses with role-based access.
